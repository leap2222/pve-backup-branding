Privacy policy

Last updated: 22 November 2026.

This policy describes how pve-backup ("the app") handles data. The app is a personal backup tool operated by a single person for their own Proxmox VE server. It is not offered as a service to third parties.

What data the app accesses

  • Files and folders in the owner's own Google Drive account that were created by the app.
  • The account's storage quota, to avoid exceeding the free 15 GB limit.

What the app does with it

  • Uploads encrypted backups of the owner's server to a single folder in the owner's Drive.
  • Deletes the previous backup of each server guest when a newer one is uploaded.

Storage and security

  • Backups are encrypted on the server (rclone crypt: content and file names) before upload.
  • Google Drive therefore stores only ciphertext; the encryption key never leaves the server.
  • OAuth credentials are stored only on the owner's server.

Sharing

  • No data is shared with third parties.
  • No analytics, advertising or tracking is used.
  • No human reads the stored data.

Revocation and deletion

  • Access can be revoked at any time from myaccount.google.com/permissions.
  • Deleting the backup folder in Drive removes all data stored by the app.
